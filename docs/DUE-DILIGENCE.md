# Buyer Due-Diligence Checklist

## Technical
- [ ] Source code reviewed
- [ ] Architecture reviewed
- [ ] CLI commands tested
- [ ] Installation tested on intended Linux distribution
- [ ] Termux installation tested if required
- [ ] Optional Nmap dependency tested
- [ ] Report generation tested
- [ ] Module health reviewed
- [ ] Known limitations documented

## IP / license
- [ ] Seller ownership evidence reviewed
- [ ] Third-party dependencies inventoried
- [ ] Open-source licenses reviewed
- [ ] Trademarks separated from source-code rights
- [ ] External service/API terms reviewed
- [ ] Exclusivity terms agreed, if applicable
- [ ] Commercialization rights agreed, if applicable
- [ ] Redistribution/sublicensing rights agreed, if applicable

## Delivery
- [ ] Final archive checksum recorded
- [ ] Secure transfer completed
- [ ] Buyer receipt confirmed
- [ ] Access materials transferred separately
- [ ] Definitive agreement executed
